# 部署核对清单

每个部署环境应在受控位置维护自己的运行记录。记录核对时间、部署提交、版本、服务状态、配置来源和回滚点。

## 索引与向量覆盖

核对读别名、物理索引、mapping、分片、副本、刷新策略及实际数据覆盖。字段已注册不代表数据已写入；查询向量模型与索引维度必须匹配。覆盖统计需要有界超时并检查失败分片。

## 服务与配置

- 核对 HTTP、MCP 和监控进程，以及存活、启动和就绪探针。
- 为本环境配置凭据、可信网络/TLS 入口、并发准入和依赖地址。
- 独立检查 Search Pipeline 是否安装并与版本化资产一致。
- 以实际 HTTP/MCP 请求检查结果；探针成功不替代业务验收。
- 监控磁盘、内存、请求延迟、错误与拒绝率，验证告警通知和恢复流程。
- 备份及恢复验证在发布前完成；只使用确认兼容的版本和数据回滚点。

操作步骤见[部署手册](deployment_runbook.md)。配置示例和基准测试结果不能代替本环境的容量与可用性验收。
